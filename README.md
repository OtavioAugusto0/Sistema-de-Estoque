# Sistema de Gerenciamento de Estoque

Sistema simples de gerenciamento de estoque desenvolvido em Python
com banco de dados SQLite.

## Funcionalidades

- Adicionar produtos
- Visualizar estoque
- Atualizar produtos
- Remover produtos
- Armazenamento dos dados em SQLite

## Tecnologias

- Python
- SQLite

## Como executar

1. Clone o repositório
2. Abra a pasta do projeto
3. Execute:

python main.py
